# Third-party assets and notices

The application uses the packages pinned in `package-lock.json`, including Next.js, React, sql.js, next-intl, Zod, Tailwind CSS, and Lucide React. Package code and icons remain under their own upstream licenses. Review the license files and notices for the exact installed versions, including transitive packages, before redistributing a built bundle or changing dependencies. Preserve license notices required by those packages.

The Farmers sprout logo, PWA icons, and court illustrations are original SVG and CSS assets created for this project. The interface also uses text, emoji, and Lucide icons. Do not add venue photos, maps, logos, fonts, sports illustrations, or other external media without recording the source, owner, license or permission, attribution requirements, and any restrictions here. A venue’s public listing does not grant permission to reuse its photographs or brand assets.

No real campus photographs or verified facility information are included in the fictional seed. Replace or remove the sample venue records before a live deployment and review the rights for any replacement content.
