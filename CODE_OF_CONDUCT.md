# Code of conduct

Farmers welcomes contributors and users across backgrounds, identities, abilities, and levels of sports experience. Project spaces should be respectful, constructive, and safe for collaboration.

Examples of unacceptable behavior include harassment, discriminatory language, sexualized attention, threats, doxxing, repeated unwanted contact, and publishing another person's private information without consent. Critique ideas and code without attacking people. Follow project maintainers’ instructions and respect community boundaries.

If you experience or witness unacceptable behavior in a project space, report it privately through the repository’s GitHub contact or private vulnerability reporting channel. Include enough context to investigate. Maintainers may remove content or restrict participation when needed to protect people and the project. Do not use a public issue to disclose sensitive personal information.

This code of conduct applies in project discussions, issues, pull requests, and other spaces represented as Farmers project spaces. It does not replace a deploying community’s own member conduct, moderation, or safeguarding policies.
